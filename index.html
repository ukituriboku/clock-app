Windows 11 アナログ時計について

この時計は外部ライブラリ・画像・フォントを一切使用せず、HTML5 Canvasと純粋なJavaScript/CSSのみで作成された完全独立型の単一ファイル（analog-clock.html）です。

インターネット接続がないオフライン環境でも、Windows 11の Microsoft Edge、Google Chrome、Brave でファイルをダブルクリックするだけで軽快に動作します。

Space
UIツールバーの表示 / 非表示（集中モード）
F
全画面（フルスクリーン）切り替え
T
カラーテーマ切り替え
M
秒針の動き（スムーズ / 1秒刻みステップ）
S
秒針チクタク音のオン / オフ（Web Audio合成音）
D
日付・デジタル時刻サブダイヤルの表示切り替え
Esc
モーダルを閉じる / 全画面終了

※ Windows 11の高DPIディスプレイ（125%, 150%, 200%拡大設定）に対応し、拡大縮小してもにじみのないクリアな描画を行います。
